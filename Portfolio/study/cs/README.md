# CS://FOUNDATION

Computer Science 학습 웹 프로젝트.

## Version
`0.1.0`

## 목표
v0.1.x에서는 실제 학습 본문을 채우지 않고 아래 토대를 먼저 완성한다.

- 전체 CS 학습 영역
- Domain / Module / Concept 데이터 모델
- 전체 Route
- 공통 Header
- 공통 Navigation
- 공통 Learning Flow
- Breadcrumb
- Previous / Next
- Roadmap
- Knowledge Map Skeleton
- Progress Skeleton
- GitHub Pages 하위 경로 `/Portfolio/study/cs`

## 배포 경로
`https://min-ser.github.io/Portfolio/study/cs/`

## Local
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

정적 빌드 결과는 `out/`에 생성된다.
