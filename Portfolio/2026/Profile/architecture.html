Design Principles

설계 원칙

프로젝트와 서비스가 달라도 일관되게 적용하는 플랫폼 설계 기준입니다.

01

Identity First

Access Key보다 Managed Identity와 Workload Identity를 우선하고 최소 권한 RBAC를 적용합니다.

02

Private by Default

PaaS 연결은 Private Endpoint와 Private DNS를 기본으로 검토하고 공개 엔드포인트 사용을 최소화합니다.

03

Observable Platform

로그, 메트릭, Trace, 배포 결과를 하나의 운영 흐름으로 연결해 장애 원인을 빠르게 분리합니다.

04

Automate Repetition

반복되는 배포, 검증, Scaling, 운영 보고를 코드로 전환해 사람의 실수를 줄입니다.
