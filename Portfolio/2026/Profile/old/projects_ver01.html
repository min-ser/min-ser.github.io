Microsoft Fabric Capacity Autoscaling

사용률 기반으로 Fabric Capacity SKU를 동적으로 상향·하향하는 자동화

2026.07

Project Overview

Fabric Capacity Metrics를 기반으로 평균 사용률과 피크 사용률을 계산하고, Notebook 또는 AKS CronJob에서 Capacity SKU를 자동 조정하는 패턴을 설계했습니다. Activator 기반 POC와 Event Hub Consumer 기반 운영형 구조를 모두 검증했습니다.

AS-IS

  • 수동 SKU 변경으로 운영 대응 지연
  • Notebook 세션 로딩과 Fabric 자원 점유
  • 고정 Capacity로 인한 비용·성능 비효율

TO-BE

  • Eventstream → Event Hub → AKS CronJob 구조
  • 최근 N분 평균·피크 기준 자동 의사결정
  • Managed Identity 기반 즉시 SKU 변경

Scaling Rule

  • 평균 사용률 60% 초과 또는 피크 100% 초과 시 상향
  • 평균 30% 미만 및 피크 50% 미만 시 하향
  • 환경별 최소·최대 SKU와 업무시간 정책 적용

Result

  • 로컬 Event Hub Consumer 수신 성공
  • PRD Capacity F32 → F16 Downscale 성공
  • Notebook 방식과 CronJob 방식 비교 검증
  • Teams 알림 및 운영 로그 구조 설계
