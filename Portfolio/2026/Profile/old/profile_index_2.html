ENGINEERING PHILOSOPHY

“작동하는 시스템보다
운영 가능한 시스템을 만든다.”

Identity First

Access Key를 편리한 기본값으로 두지 않습니다. Managed Identity와 Workload Identity를 먼저 검토합니다.

Private by Default

공용 네트워크 차단, Private Endpoint, DNS, NSG, 방화벽을 하나의 통신 경로로 설계합니다.

Build to Operate

구축 완료가 아니라 배포 이후의 모니터링, 변경, 장애 대응, 비용까지 포함해 설계합니다.

Document the Decision

무엇을 했는지보다 왜 그렇게 결정했는지 Architecture Decision과 Runbook으로 남깁니다.

Validate with Code

설계는 FastAPI, Python, Java, Pipeline, CronJob 같은 실행 가능한 코드로 검증합니다.

Standardize Repetition

반복되는 이슈는 Naming Rule, Sample Code, CI/CD Template, Validation Tool로 전환합니다.
