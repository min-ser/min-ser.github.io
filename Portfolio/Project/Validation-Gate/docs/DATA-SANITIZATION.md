# Data Sanitization Policy

This portfolio must never include names or values that identify or imply a real employer, customer, internal project, environment, resource, endpoint, network, workspace, subscription, ticket, or credential.

## Required demo convention

- Organization prefix: `kms`
- Resource names: fictitious `kms-*` values only
- Network addresses: documentation/demo ranges only
- Tokens, certificates, request IDs, and secrets: visibly invalid demo values only

This policy applies to HTML, CSS, JavaScript, JSON, logs, examples, screenshots, README files, and all future releases.
