3개 항목을 확인하면 다음 단계 안내가 표시됩니다.

연결이 안 되나요?

호텔 Wi-Fi가 없어요

휴대폰 핫스팟을 켜고 노트북을 연결하거나, 휴대용 공유기로 로컬 네트워크를 구성하세요. 휴대폰 핫스팟에서 연결된 노트북으로 접속할 수 있는지는 기종·OS별 확인이 필요합니다.

핫스팟을 켰는데 접속이 안 돼요

두 기기가 같은 네트워크인지, 기기 간 통신 차단 여부, Windows 방화벽과 서버 LAN 바인딩 설정을 확인해야 합니다. 현재 데모에는 서버가 없습니다.

인터넷 없이 QR을 쓸 수 있나요?

가능합니다. QR에는 노트북의 로컬 주소를 넣습니다. 단, 실제 접속에는 실행 중인 서버와 로컬 네트워크, 인증·HTTPS 설정이 필요합니다.

사진은 어디에 저장되나요?

최종 제품에서는 스마트폰에서 촬영한 사진을 고객 노트북으로 전송해 암호화 저장합니다. 이 퍼블리싱 HTML은 사진을 서버로 전송하지 않습니다.

보안 설계 원칙: 인터넷이 없어도 로컬 접속 가능 · 외부 클라우드로 사진 전송 없음 · 실제 모바일 접속 시 기기 승인/인증 및 신뢰 가능한 HTTPS 필요. Wi-Fi·핫스팟은 네트워크 기능이며 인터넷 연결과는 다릅니다.
