# 천류관 에셋 관리 가이드

## 한글화 원칙

- 실행 코드, JSON 내부 ID, 브라우저가 직접 읽는 경로는 영어를 유지합니다.
- 작업자용 에셋 폴더, 문서, 체크리스트, 원본 파일명은 한글을 사용합니다.
- 원본은 `에셋/` 아래에 보관하고, 게임 사용본은 `game/assets/`에 별도 복사합니다.

## 구조

```text
에셋/
├── 캐릭터/
├── 배경/
├── 이벤트CG/
├── UI/
├── 효과/
├── BGM/
└── 효과음/

문서/
├── 체크리스트/
└── 에셋_가이드/
```

## 게임 적용 전 검수

1. 실제 투명 PNG 여부
2. 체크무늬 배경 포함 여부
3. 검 끝·머리카락 잘림 여부
4. 손가락·무기 손잡이 형태
5. 얼굴·복장·체형 일관성
6. 캔버스 크기와 발 위치 기준선
7. WebP 변환 화질과 용량
8. 영어 리소스 ID 연결
