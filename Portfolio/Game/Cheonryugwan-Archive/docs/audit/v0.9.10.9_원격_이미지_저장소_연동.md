# v0.9.10.9 원격 이미지 저장소 연동

## 재확인 결과
- 1부: GitHub 한글 번호 파일 29개 확인 → 원격 사용
- 2부: GitHub에 영문 생성 프롬프트형 PNG 31개만 존재 → 자동 매핑 중단, 로컬 32개 유지
- 3부: GitHub 한글 번호 파일 40개 확인 → 원격 사용
- 4부: GitHub 한글 번호 파일 01~28, 30 총 29개 확인 → 해당 항목만 원격 사용, 나머지 17개 로컬 유지

## 프로젝트 정리
- 검증된 원격 배경의 프로젝트 내 WebP 및 썸네일 삭제: 205파일
- 배경 논리 ID는 유지하여 기존 시나리오 JSON 호환
- `data/asset-config.json` 추가
- Manifest에 `assetSource`, `remoteFile`, `remoteUrl` 기록
- 웹 배경 갤러리도 같은 원격 PNG 사용
- 2부는 파일명이 정상화되기 전까지 원격 연결하지 않음

## 중요
원격 저장소의 파일명만 보고 2부 영문 PNG를 임의 순서로 연결하지 않았다.
잘못된 장면 매핑보다 로컬 보존을 우선한다.
