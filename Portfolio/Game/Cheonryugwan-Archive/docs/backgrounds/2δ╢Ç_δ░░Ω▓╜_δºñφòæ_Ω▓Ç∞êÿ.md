## 호환성

- `bg-01.webp` ~ `bg-32.webp`의 기존 번호 체계는 유지한다.
- `bg-18.webp`는 프로젝트 시나리오/게임 데이터에서 직접 참조되지 않는 것을 확인한 뒤 제거했다.
- 이름 변경은 갤러리와 `data/part-2-backgrounds.json` 표시 메타데이터에 적용되며 게임의 기존 Scene ID에는 영향을 주지 않는다.
