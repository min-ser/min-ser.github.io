# ZIP and Archive Storage Guide

- Story ZIP: `archives/source-zips/story/`
- Image ZIP: `archives/source-zips/images/`
- Reference ZIP: `archives/source-zips/references/`
- Imported projects: `archives/source-zips/imports/`
- Release ZIP: `archives/generated/releases/`
- Reports: `archives/generated/reports/`
- Analysis: `archives/generated/analysis/`
- Backups: `archives/backups/`

Large binary files are excluded from Git by default.
