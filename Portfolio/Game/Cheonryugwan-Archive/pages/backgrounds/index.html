배경

1~4부 고화질 배경을 동일한 카드 배열로 확인합니다. 2부는 실제 이미지 기준 이름 매핑을 재검수했습니다.

갤러리 보존 원칙 — 1~4부에 웹 등록된 배경은 게임 사용 여부와 관계없이 모두 표시하며, 중복 최적화 시에도 카드 노출은 유지합니다.
전수검수 완료 — 깨진 한글 파일명 복구, 1~4부 배경 파일/표시명/이미지 매핑 재검수, 잘못 연결된 고화질 이미지를 교정했습니다.
이미지 저장소 연동 — 파일명/번호가 검증된 배경은 Cheonryugwan-Image의 원본 PNG를 직접 사용합니다. 2부와 아직 업로드되지 않은 4부 항목은 안전하게 로컬 이미지를 유지합니다.
GitHub 이미지 저장소 연동 — 2부 32개 한글 파일명을 다시 확인하여 모두 원격 PNG로 전환했습니다. 파일명/번호가 검증된 이미지만 원격으로 사용합니다.
