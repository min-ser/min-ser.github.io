# Character Visual References

사용자가 제공한 캐릭터 이미지 원본을 보존하는 폴더입니다.

## 원칙

1. 원본 파일을 직접 수정하거나 덮어쓰지 않습니다.
2. 파일명만 프로젝트 규칙에 맞춰 복사본으로 정리했습니다.
3. 이미지의 해시는 `VISUAL_REFERENCE_MANIFEST.json`에 기록합니다.
4. 게임용 WebP, 투명 스탠딩, 초상화, 표정 이미지는 별도 파생 에셋입니다.
5. 캐릭터 설정과 이미지가 충돌할 경우 작성자가 최종 기준을 결정합니다.

## 포함 자료

- 전서율
- 서하린
- 설유진
- 연무설
- 적월아
- 혈천무후 진하연과 천마교주 연서의 2인 CG 레퍼런스
