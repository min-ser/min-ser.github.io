# Character Bible

캐릭터의 공식 설정과 이미지 자료를 관리합니다. `_SOURCE/`는 전달받은 원본이며 수정하지 않습니다.

## 분류

- `protagonists/`: 주인공 및 서사의 중심 인물
- `main-cast/`: 메인 캐릭터
- `orthodox/`: 정파
- `unorthodox/`: 사파
- `demon-cult/`: 마교
- `cheonryugwan/`: 천류관 인물
- `npc/`: 기타 인물

## 새 캐릭터 추가

`templates/CHARACTER_BIBLE_TEMPLATE/`를 복사하고 ID는 kebab-case로 작성합니다. 원본 설정을 받은 경우 먼저 `_SOURCE/날짜/`에 보존한 뒤 Character Bible에 정리합니다.

## 이미지

- `official/`: 확정 이미지
- `concept/`: 디자인 시안
- `expressions/`: 표정 이미지
- `references/`: 참고 자료
