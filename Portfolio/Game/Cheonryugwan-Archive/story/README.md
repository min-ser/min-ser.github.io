# Story Workspace

## 문서 구분

- `story/_INBOX/`: 전달받은 원본 파일. 수정 금지
- `story/outline/`: 부·장·화·장면을 설계한 스토리 아웃라인/트리트먼트
- `story/synopsis/`: 권별 또는 부별 줄거리 요약
- `story/manuscript/`: 실제 소설 원고를 집필하는 위치
- `story/game-script/`: 원고를 인터랙티브 노벨 대본으로 변환한 결과
- `story/analysis/`: 구조·인물·장면 분석
- `story/reports/`: 검토 보고서
- `story/timeline/`: 작품 연표
- `story/foreshadow/`: 복선 등장·회수표
- `story/glossary/`: 고유명사와 작품 용어

## 실제 소설 집필 위치

```text
story/manuscript/volume-01/part-01/chapter-01.md
```

현재 전달된 1~4부 문서는 실제 소설 원고가 아니라 `outline/volume-01/`에 배치된 상세 스토리 아웃라인입니다. `_INBOX` 원본은 그대로 보존됩니다.
