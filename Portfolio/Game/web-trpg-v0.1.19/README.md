# Web TRPG v0.1.19

## 퍼블리싱 데모 실행
`index.html`을 브라우저에서 열고 `게임 참가` → `더미방 표시` → 방 선택 → 닉네임 입력 → 대기실 입장 → 역할 및 캐릭터 선택 → 준비 완료 → 게임 시작을 진행합니다.

`게임 시작`을 누르면 **3·2·1 카운트다운과 화면 효과 후 기존 시네마틱 게임 화면**으로 이동합니다. 새 텍스트 게임 화면은 더 이상 게임 시작 경로에서 사용하지 않습니다.

- `GM 전담`: 캐릭터를 선택하지 않아도 준비 및 시작할 수 있습니다.
- `GM 겸 플레이어`: 캐릭터를 선택해야 합니다.
- `플레이어`: 캐릭터를 선택해야 합니다.
- GM 전담/겸 플레이어는 기존 시네마틱 화면 위에 GM 보조 도구가 표시됩니다. 도구는 퍼블리싱 데모이며 서버와 동기화되지 않습니다.

## 실제 서버
Node.js 18 이상에서 `node server.js`를 실행하고 `http://127.0.0.1:3000/index.html`로 접속합니다. 데모가 아닌 실제 서버 모드에서는 별도 API 흐름을 사용합니다.

## 검증 및 주의
Node.js JavaScript 구문 검사 통과. 실제 브라우저 자동 클릭 검수는 환경에 Chromium 실행 파일이 없어 미완료입니다. 데모방, 준비 상태, GM 도구 및 장면 진행은 브라우저 로컬 퍼블리싱 시뮬레이션이며 실제 멀티플레이가 아닙니다.
