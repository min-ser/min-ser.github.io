# 천류관 Novel Archive — 디자인 시안 인덱스 (v0.6.4)

이 폴더의 PNG는 목표 디자인 이미지이며 HTML 구현 완료를 의미하지 않습니다. 이미지 안의 글과 사건은 시각적 예시입니다. 실제 프로젝트 원고에는 반영하지 않습니다.

- `novel-library.png`: 소설 목록 · 작품 소개 — a_detailed_cinematic_website_ui_in_korean_with_a.png
- `reader-main.png`: 고서형 리더 · 본문 — a_detailed_ornate_ui_fantasy_book_reader_scene_ci.png
- `reader-controls.png`: 고서형 리더 · 목차 및 읽기 설정 — a_detailed_cinematic_ui_concept_art_a_full_scree.png
- `reader-cover.png`: 고서형 리더 · 표지와 두 쪽 — a_detailed_ornate_web_ui_reading_interface_a_wide.png
- `reader-blank.png`: 고서형 리더 · 한지와 장정 — a_richly_detailed_cinematic_ui_scene_for_a_novel_r.png
- `world-atlas.png`: 세계관 · 무학 — a_highly_detailed_ornate_ui_desktop_web_interface.png

## 구현 우선순위
1. 소설 목록: 실제 회차 데이터로 목록/작품 정보 표시
2. 독서 화면: 표지·두 쪽·장식·읽기 도구를 시안에 근접하게 조정
3. 세계관: 실제 공개 CANON 문서로 지도/세력 탐색 구현
4. 캐릭터/관계/의상/통합 설정집: 추후 개별 시안 제작 및 구현

## 검수 기준
- 실제 원고와 디자인 시안은 분리
- 모바일/키보드/모션 감소 지원
- 시안 이미지 자체를 소설 페이지 배경으로 사용하지 않음
