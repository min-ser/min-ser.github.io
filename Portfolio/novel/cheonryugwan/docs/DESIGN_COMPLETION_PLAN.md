# 천류관 Novel Archive — 공식 디자인 시안 기반 완성 계획

기준: v0.9.0 소스 (`Portfolio/novel/cheonryugwan/`) 및 `docs/design/`의 PNG 7장, `DESIGN_REFERENCE_INDEX.md`, `READER_DESIGN_TARGET.md`.
작성일: 2026-11-22. 상태는 **소스 정적 검토** 기준. 실제 브라우저/운영 배포 검수는 수행하지 않음.

## 0. 검토 결론
- **기술적으로 구현 가능**: HTML/CSS/JS로 입체 책, 2쪽 독서, 사이드 패널, 목차, 배경 연출, 반응형 구현 가능.
- **현재 구현과 목표 시안의 격차 큼**: 기존 CSS의 일반 카드·배너 중심 레이아웃을 단순 꾸미는 것으로는 부족. 소설 서가/리더/세계관의 화면 구조를 재설계해야 함.
- **기능 재사용 가능**: `app.js`의 원고 목록, `reader()`, 페이지 분할, 이동 및 데이터 동기화 구조를 우선 보존.
- **불확실성**: 실제 Private NOVEL 원고/공식 이미지 연결, 브라우저 동작, 운영 배포, 모바일 UX는 별도 확인 필요.
- **주의**: 시안 PNG의 글/사건은 예시. 실제 원고로 반영 금지. 시안 전체를 배경 이미지로 사용해 UI를 대체하지 않음.

## 1. 화면별 시안-구현 차이
| 영역 | 기준 파일 | 현재 소스 검토 | 목표 |
|---|---|---|---|

| 고서 표지 | `reader-cover.png` | 표지 진입 기능 존재 | 실제 입체 가죽 표지와 펼침 전환 |
| 고서 본문 | `reader-main.png`, `novel-reader-target-v0.6.3.png` | 양면 페이지 및 분할 코드 존재 | 화면 중심 대형 책, 한지 질감, 책등, 좌우 균형, 장식 |

| 캐릭터/관계/의상 | 개별 공식 PNG 없음 | 기능 및 기본 UI 존재 | 별도 시안 확정 후 일관된 시스템으로 재설계 |
