# 천류관 Novel Archive — 통합 업데이트 로드맵

기준 버전: v0.6.4 / 계획 갱신: 2026-11-22

## 고정 개발 원칙
1. **실제 프로젝트 코드 먼저 수정** → 실행·빌드·동작 검증 → 전체 프로젝트 ZIP → 실제 코드 기반 채팅 내 HTML 퍼블리싱 → 체크리스트 갱신.
2. 실제 프로젝트의 소설 본문·이미지는 `min-ser/NOVEL/CHEONRYUGWAN`에서 동기화한 데이터만 사용한다. 시연용 예시 원고는 **별도 퍼블리싱 미리보기**에만 둔다.
3. 동기화 실패는 오류로 알리고 가상 원고나 이미지를 대체 표시하지 않는다.
4. 로컬 실행은 `npm install` → `npm run dev`; 빌드는 `npm run build`. Git 블로그 배포는 최초 워크플로 연동 후 Push만으로 작동하도록 설계한다.
5. 디자인 시안은 구현 완료의 증거가 아니다. 시안과 실제 화면을 구분해 검수한다.

## 시안 기반 검수 기준
- **외형:** `docs/design/novel-reader-target-v0.6.3.png`와 배경·책·표지·여백·조작부 비교.
- **읽기:** PC에서는 좌우 두 쪽이 화면 내에 보이며 페이지를 읽기 위해 외부 세로 스크롤하지 않음.
- **연출:** 표지→책 펼침→실제 회차 이미지의 부드러운 등장/소멸→본문, 페이지 넘김은 회차 내 페이지 단위.
- **콘텐츠:** 실제 원고만 사용하고, 이미지가 없거나 원고 연결이 실패하면 사실대로 표시.
- **접근성:** 모바일에서 텍스트 판독 가능, 모션 감소 시 애니메이션 축소, 키보드·터치 지원.
- **검증:** 시각 검수, 브라우저 조작 검수, 실제 GitHub 원고·배포 검증은 각각 별도 완료 표시.
