# 천류관 v0.9.30 공통 디자인 시스템 및 코드 검수

## 이번 작업
- 기존 v0.9.29 소스를 유지하면서 공통 디자인 토큰(`design-tokens.css`)과 공통 컴포넌트 규칙(`design-components.css`)을 추가했다.
- 색상, 간격, 경계선, 그림자, 포커스 표시 등 공통 값의 기준점을 만들었다.
- 기존 레이아웃 관련 CSS를 삭제하지 않고 우선 스타일 적용 순서를 명시적으로 검증한다.
- 홈 히어로 캐릭터 제거 상태와 NOVEL 자동 수집 코드는 변경하지 않았다.
