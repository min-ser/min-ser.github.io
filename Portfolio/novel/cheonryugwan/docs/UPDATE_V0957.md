- 운영 app.js의 생성 마크업과 독립 퍼블리싱 HTML은 여전히 완전히 동일하지 않음.

- 신규 고지도는 개념 UI이며 정식 지리 설정을 확정한 지도가 아님.
- ZIP/HTML 정적 검증과 실제 브라우저 시각 검증은 별개임.
