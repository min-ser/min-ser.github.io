# v0.9.35 CSS 중복 정리 및 공통 책임 재배치

- `design-components.css`의 중복된 좁은 범위 포커스 선언 1개 제거. 넓은 공통 `:focus-visible` 선언 유지.
- 제목 타이포그래피를 `archive-unified.css`에서 `design-components.css`로 이동. 제목 여백과 장식선, 반응형 배치는 기존 페이지 CSS에 유지.
- CSS 소유권 자동 검증 추가.
- 기존 홈 히어로 캐릭터 비노출 및 캐릭터 도감 유지.
- 레거시 선택자/미디어쿼리의 무차별 삭제는 하지 않음.

검증은 npm check, 통합 테스트, 실제 브라우저의 홈/소설/세계관 PC·모바일 캡처를 기준으로 별도 확인.
