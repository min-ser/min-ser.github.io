# v0.6.8 참고용 퍼블리싱

실제 프로젝트의 `index.html` 스타일과 `app.js` 상호작용을 기반으로 별도 독립 HTML 미리보기를 제공합니다.

- 채팅 제공 파일: `cheonryugwan_v0.6.8_reference_preview.html`
- 원고: **미리보기 전용 예시 3화**. 실제 원고 아님.
- 실제 프로젝트 `static/content.json`은 `NOT_SYNCED` 상태 그대로이며 예시 원고가 들어 있지 않습니다.
- 미리보기에서 홈 → 소설 → 회차 → 표지 열기 → 이전/다음 책장을 조작할 수 있습니다.
- 목표 디자인 갤러리 6종을 같은 HTML에서 확인할 수 있습니다.
