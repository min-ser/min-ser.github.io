# 공식 이미지 매핑 검토 절차

1. NOVEL 원본 공개 가능 이미지인지 확인합니다.
2. 사이트 `#costumes` → 공개 이미지 자산 열람실 → 이미지 열람하기 → **연결 검토**를 선택합니다.
3. 인물·유형·설명을 선택하고 JSON 초안을 복사합니다.
4. 원본 캐릭터 설정과 일러스트의 인물이 실제로 일치하는지 검토합니다.
5. 승인된 이미지에 한해 `static/character-images.json`의 `galleries` 배열에 `{url,type,label}`를 수동 등록합니다. 대표 이미지는 `portraits`에 등록합니다.
6. `npm run check`, `npm run test:integration`, 실제 원고 빌드 및 운영 브라우저를 검증합니다.

**중요:** 검토서에서 복사한 JSON은 운영 매핑 파일에 자동 저장되지 않습니다. 미승인 이미지를 자동 등록하지 않습니다.
