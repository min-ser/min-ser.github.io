## 원고 동기화 재개
원고 저장소가 체크아웃된 환경에서 `NOVEL_SOURCE_DIR=/path/to/checkout npm run build`를 실행. `01_NOVEL` 폴더가 있는 원본 경로가 필요함. 실패 상태로 운영 빌드를 성공 처리하지 않음.
