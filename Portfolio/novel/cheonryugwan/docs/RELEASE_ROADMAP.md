# 《천류관 Novel Archive》 릴리스 로드맵 — v0.9.x → v0.10.x

작성: 2026-11-23 | 기준: v0.9.49 계획본 | 상태: 개발 계획 (미구현 항목은 완료로 표시하지 않음)

## 1. 릴리스 정책

- **v0.9.x: 고서형 UI/UX 웹 디자인 완성.** 홈, 서가, 표지, 독서, 세계관, 인물, 아카이브의 화면 구성과 기능을 완성한다. PC·모바일은 데이터와 브랜드를 공유하되 화면 구성을 각각 설계한다.
- **v0.10.x: 특수효과·이벤트 연출 완성.** v0.9.x에서 확정한 UI 위에 아우라, 기류, 입자, 배경 움직임, 고서 전환, 스토리 이벤트를 추가한다.
- **버전 경계:** v0.9.x에서는 새로운 시각 효과 개발을 하지 않는다. 단, 가독성·기능상 필수인 최소한의 상태 전환과 접근성 피드백은 허용한다. v0.10.x에서 화면 구조를 대대적으로 바꾸지 않는다.
- **기존 v0.9.43~v0.9.48의 이펙트:** 참고 구현으로 보존하고 v0.10.x에서 재평가한다. 검증되지 않은 효과를 운영 화면에 무조건 이식하지 않는다.
- **데이터/운영:** 검수용 더미 원고는 운영에 반영하지 않는다. 실제 NOVEL/CANON과 콘텐츠 경로를 유지한다. 독립 미리보기와 운영 소스 적용을 구분한다.

## 4. 작업 산출물 규칙

매 버전: (1) 변경된 실제 프로젝트 소스, (2) PC/모바일 브라우저 미리보기, (3) 전체 프로젝트 ZIP 하나, (4) 누적 체크리스트와 변경 로그, (5) 적용/미적용 및 검증 상태를 함께 제공한다. 화면만 만든 경우 '퍼블리싱 검수본'으로 표기한다. 파일명은 문서 종류별로 고정하고 버전은 문서 내부 및 릴리스 태그에서 관리한다.

## 5. 즉시 착수 범위

다음 구현 버전은 **v0.9.49 서가 디자인 시스템**이다. `docs/design/novel-library.png` 등 공식 시안을 기준으로 기존 `index.html`, `app.js`, CSS, 콘텐츠 경로를 점검한 뒤 PC 3영역/모바일 전용 서가를 실제 운영 코드에 적용한다. 신규 이펙트 작업은 v0.10.0까지 보류한다.
